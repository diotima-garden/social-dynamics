# Drills — how to run one

One subfolder per drill: its own context, rubric, and versioned simulator artifacts. This
file is the shared part. Read it before running a drill; read the drill's own `context.md`
for what it trains.

**Drills available:**

| Drill | Register | When to pick it |
|---|---|---|
| `dating-frame` | Status pressure — probing questions, shit-tests, late cancellations, vulnerability checks. | The relationship is new or exitable and the pressure is a test. |
| `saying-no` | Obligation pressure at work and in the family — guilt-trips, unasked-for advice, assumed favours. | The relationship does not end, and the cost of the reply outlives the exchange. |

Offer both when the practitioner hasn't said which. They share `../principles.md` and this
procedure; rubrics differ because the registers differ.

## Running one

"Continue with the drills" (or similar) is the request this answers. Don't ask for a
prompt, don't invent a drill.

1. **Pick the menu source, highest first:**
   - **Private layer**, if orientation reported one — read it on demand (never a filename
     or content outside this read). It already names the single active target and the
     queue; use that directly rather than re-deriving a menu.
   - **The bank**, if there's no private layer or it's silent on what's next — patterns it
     flags as unfinished (`../memory/small-bank.md`).
   - **`../principles.md`**, only if neither source gives a signal.

   Tracked files (`./<name>/context.md`, `rubric.md`, `artifacts/simulator.md`) own scenario
   *classes* — method, fork-safe. The private layer only supplies which class is live and a
   session's throwaway texture; that texture never gets written back to a tracked file.

2. **Read the drill's own files** — not auto-injected: `./<name>/context.md`,
   `./<name>/rubric.md`, `./<name>/artifacts/simulator.md` (always the live one; adopt it,
   don't hand it over; ignore older versions in `artifacts/`).

3. **Run it here.** You are the simulator. Grade every rubric dimension, both failure
   directions.

4. **Don't hand-write the bank.** Capture is automatic via `../memory/this-bank-prompt.md`'s
   de-identifying transform. A `calibration.md` entry built from a private-layer scenario
   must be re-generified the same way before it lands — or it doesn't land.

## The ceiling

Text drills train recognition and having a reply ready (rungs 1–2 of `../principles.md`),
not composure under real pressure (rung 3) — that needs `../reps/`. See `../research/`.
