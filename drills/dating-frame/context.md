# Drill — Dating Frame-Control

Holding a strong, unbothered, playful frame under dating pressure: probing questions,
shit-tests, late cancellations, vulnerability checks. The simulator throws a scenario, you
respond, it grades you against `./rubric.md`, names the move the reply was missing, reports
how the other party would likely feel receiving it, then escalates.

"Playful frame, don't leak neediness" is this drill's idiom for the grove-level target of
**calibrated assertiveness** (`../../principles.md`) — held in the register that dating
pressure calls for.

How a drill is picked and run is shared across drills and lives in `../context.md`.

| Path | What |
|---|---|
| `./artifacts/simulator.md` | The live operating instruction — adopt it, don't hand it over. Always this path; revisions replace the file. |
| `./rubric.md` | This drill's grading dimensions: Detection / Subtext / Leverage / Thermodynamics. |
| `./calibration.md` | The gold-standard set the grader is anchored to — five cases with known correct grades, spanning both failure poles. Re-run it whenever the simulator is revised. Live tier-2 answers are its intake path. |

Shared stance and failure modes live one level up in `../../principles.md`.
